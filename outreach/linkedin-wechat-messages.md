**How to use these**
- **Two steps.** Send the short **connection note** with the invite. Send the **follow-up** only once they accept.
- **Note length.** LinkedIn caps notes at 300 characters, and every note below fits. Free accounts can only send a few personalised notes a month, so if you're limited, start with the ⭐ people.
- **One person per company at a time.** Messaging four Zung Fu directors on the same day looks like spam. Start with the ⭐ person, wait about a week, then try the next one.
